### 项目简介

**要点：**

- `nav-sdk-demo` 是 Telenav Navigation SDK（TASDK）官方 Android 示例
- 演示从 SDK 初始化到地图、搜索、算路、导航的完整链路
- 客户可在此基础上快速验证集成，再迁移到自有工程

**Demo 覆盖能力：**

| 模块 | 能力 |
|------|------|
| Map SDK | 地图展示、手势、交通、标注 |
| Navigation | 算路、开始/停止导航、跟车模式 |
| SearchService | 关键词/分类/框选搜索、自动补全、详情、Google 搜索 |

- Android SDK 33
- 设备：Android 8.0+（API 26），需网络

### 第 6 页｜MainActivity 职责

## 第二部分：讲解脚本（约 25–30 分钟）

### 【开场】约 1 分钟

> 大家好，今天介绍 Telenav Navigation SDK 的 Android 示例应用 **nav-sdk-demo**。  
> 这个 Demo 演示从 SDK 初始化到地图展示、POI 搜索、路线规划和导航的完整集成链路。  
> 大家可以把它当作集成参考，验证通过后再迁移到自己的工程。

---

### 【项目简介】约 2 分钟

> Demo 覆盖三块核心能力：  
> **第一，地图**——展示、手势、交通、标注；  
> **第二，导航**——算路、开始/停止导航、跟车模式；  
> **第三，搜索**——通过我们提供的 **SearchService** 统一接入，包括关键词搜索、分类搜索、框选搜索、自动补全、POI 详情，以及 Google 搜索。  
>  
> 搜索方面，客户只需对接 SearchService 这一套 API，不需要关心内部如何选源或 fallback。

---

### 【整体架构】约 3 分钟

> 架构分三层。  
>  
> **最上层是 Demo App**：`SplashActivity` 负责启动和初始化；`MainActivity` 负责地图、导航和搜索联动；搜索 UI 由 `SearchOverlayController` 等组件承载，业务状态在 `SearchViewModel` 里管理。  
>  
> **中间是配置层**：`gradle.properties` 配置 Region、API Key、Endpoint；`SdkCredentials` 负责读取和解密凭证。  
>  
> **底层是 Telenav SDK**：Map SDK 负责地图和算路，Navigation 负责导航，**SearchService 是搜索的统一对外服务**。  
>  
> 可以记一句话：**地图和导航走 TASDK，搜索统一走 SearchService。**

*（切到架构图页）*

### 【启动流程】约 2 分钟

> 用户点击图标后，先进入 `SplashActivity`。  
> 第一步申请定位、网络等权限；  
> 第二步用 `SDKOptions` 初始化 Map SDK；  
> 第三步初始化 SearchService；  
> 成功后跳转 `MainActivity`，初始化地图、绑定搜索 UI、注册导航事件监听。  
>  
> 整个启动链路在 `SplashActivity` 里完成，客户集成时重点看这一个类。

---

### 【SearchService】约 3 分钟

> 搜索是我们提供的完整对外服务，集成方通过 SearchService 接入即可。  
>  
> 主要 API 包括：  
> - `wordPredictionRequest()` 单词预测  
> - `suggestionPredictionRequest()` 自动补全  
> - `searchRequest()` 文本、分类、框选搜索  
> - `getDetailRequest()` POI 详情  
> - `isGoogleSearchAvailable()` 判断当前区域 Google 搜索是否可用  
>  
> Demo 里，`SearchViewModel` 调用这些 API，`SearchOverlayController` 负责 UI 展示。  
> 选中 POI 后会自动在地图上设目的地、算路，并可一键发起导航。  
>  
> 有两个注意点：  
> 1. SearchService 在应用启动时初始化一次，是进程内单例；  
> 2. `initialize()` 和 `execute()` 都是同步阻塞的，必须在后台线程执行，不能放主线程。

## 第四部分：集成步骤（客户实操清单）

### 步骤 1：环境准备

- Android Studio + JDK 11+
- Android SDK 33
- 真机或模拟器：Android 8.0+（`minSdkVersion 26`），需 GPS 与网络

### 步骤 2：获取工程

```bash
git clone git@github.com:Telenav/nav-sdk-demo.git
```

> 若需在 `develop` 分支上叠加 Google 搜索能力，可参考 `patches/README.md` 应用 patch。

### 步骤 3：配置 Maven 仓库

在根目录 `build.gradle` 的 `allprojects.repositories` 中配置 Telenav Maven 仓库（含阿里云镜像及访问凭证）。客户需向 Telenav 获取仓库访问权限。

### 步骤 4：配置凭证与 Region

编辑 `gradle.properties`：

```properties
Region=EU
API_KEY=your-api-key
API_SECRET=your-api-secret
CloudEndPoint=https://apieustg.telenav.com
APP_NAME=YourAppName
```

- **EU / SEA** 等区域在文件中均有示例，切换 Region 时需同时改 `API_KEY`、`API_SECRET`、`CloudEndPoint`
- 凭证支持明文，也支持 `enc:` 前缀的 AES 加密格式（见 `SdkCredentials.kt`）

### 步骤 5：添加 SDK 依赖

在 `app/build.gradle` 中配置核心依赖：

```gradle
// 地图 & 导航
implementation "com.telenav.sdk:telenav-android-mapview-${ndkVersion}:${telenavSdkVersion}"
implementation "com.telenav.sdk:telenav-android-navigation-${ndkVersion}:${telenavSdkVersion}"
implementation "com.telenav.sdk:telenav-android-ehservice-${ndkVersion}:${telenavSdkVersion}"
implementation "com.telenav.sdk:telenav-android-ngx-${ndkVersion}:${mapPluginVersion}"
implementation "com.telenav.sdk:telenav-entity-hybrid:${entityVersion}"
implementation "com.telenav.sdk:telenav-sdk-base:${baseVersion}"

// 搜索（统一对外服务）
implementation "com.telenav.search:search-service:${search_service_version}"
```

版本号统一在 `gradle.properties` 维护。

### 步骤 6：初始化 SDK

**地图 SDK**（参考 `SplashActivity.kt`）：

| 配置项 | 说明 |
|--------|------|
| `setApiKey` / `setApiSecret` | 客户凭证 |
| `setCloudEndPoint` | 云端服务地址（纯流式模式必填） |
| `setSdkCacheDataDir` | 可写缓存目录 |
| `setRegion` | 区域（EU/SEA/CN 等） |
| `setUserId` / `setDeviceGuid` | 用户/设备标识 |
| `setApplicationInfo` | 应用名称与版本 |

**SearchService**（同样在 `SplashActivity` 中初始化）：

```kotlin
SearchServiceHolder.initialize(context, latitude, longitude)
```

- 进程内单例，在应用级初始化一次
- 初始化参数见 `SearchServiceConfig.buildInitOptions()`
- 不要在 `Activity.onDestroy()` 中释放；在应用退出时调用 `SearchServiceHolder.release()`

### 步骤 7：展示地图（参考 `MainActivity.kt`）

1. 在布局中声明 `com.telenav.map.views.TnMapView`
2. 调用 `mapView.initialize(MapViewInitConfig)` 并监听 `MapViewReadyListener`
3. 在 `onResume` / `onPause` 中调用 `mapView.onResume()` / `onPause()`
4. 在 `onDestroy` 中释放 SDK 资源

### 步骤 8：算路与导航

| 操作 | API |
|------|-----|
| 算路 | `DirectionClient.Factory.hybridClient().createRoutingTask()` |
| 绘制路线 | `mapView.getRoutesController()?.add(routes)` |
| 开始导航 | `NavigationService.Factory.createInstance().startNavigation(route, ...)` |
| 停止导航 | `driveSession.stopNavigation()` |
| 位置注入 | `SDK.getInstance().injectLocationProvider(locationProvider)` |

### 步骤 9：集成搜索

搜索统一通过 **SearchService** 对外 API 接入：

| 能力 | SearchService API |
|------|-------------------|
| 单词预测 | `getClient().wordPredictionRequest()` |
| 自动补全 | `getClient().suggestionPredictionRequest()` |
| 文本/分类/框选搜索 | `getClient().searchRequest()` |
| POI 详情 | `getClient().getDetailRequest()` |
| Google 可用性 | `SearchService.isGoogleSearchAvailable()` |

Demo 中的调用链路：

1. `SplashActivity` → `SearchServiceHolder.initialize()`
2. `SearchViewModel` → 发起各类搜索请求
3. `SearchOverlayController` → 绑定搜索 UI
4. 选中 POI → 触发算路与导航

> `initialize()` 与 `execute()` 均为同步阻塞调用，须在后台线程（如 `Dispatchers.IO`）执行。

### 步骤 10：编译运行

```bash
./gradlew assembleDebug
```

输出 APK：`nav-sdk-demo-debug.apk`
